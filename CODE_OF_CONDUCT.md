# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The short version:

- Be respectful. Critique code and ideas, not people.
- Assume good intent. Most disagreements here are about Windows behaviour, not about you.
- No harassment, insults, bigotry, or sustained disruption in issues, pull requests or
  discussions.
- Keep reports about the software. Do not post other people's personal data, logs with
  usernames or hostnames, or screenshots that were not yours to share.

## Scope

This applies to issues, pull requests, commit messages, and any space where someone is
representing the project.

## Enforcement

Report a problem to the maintainer at <https://github.com/nithu-only> — for anything
sensitive, use the private channel in [SECURITY.md](SECURITY.md) instead. Reports are
reviewed by the maintainer. Responses range from a request to edit a comment, to closing a
thread, to a temporary or permanent ban from the repository.

The maintainer is also bound by this code.
